## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Room Layout** | Design base floor plans with prefab rooms and corridors |
| **Farm Designer** | Plan crop planter layouts and hydroponic unit placement |
| **Material Calc** | Calculate nanites and resources needed for your build plan |
| **Portal Tracker** | Log portal glyphs and base coordinates per planet visited |
